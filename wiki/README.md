# LLM Wiki

Personal knowledge vault curated by Claude Code, following Karpathy's LLM Wiki pattern (read once, structure once, grow over time — not RAG over raw docs).

- **Sources/** — raw ingests, immutable
- **Topics/** — synthesis, this is where queries get answered
- **People/** — creators and figures
- **Digests/** — farmer run output, chronological
- **farmers/** — scheduled-ingest configs

See `CLAUDE.md` for curator rules. Open this folder in Obsidian as a vault.

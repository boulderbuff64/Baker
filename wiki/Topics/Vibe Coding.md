# Vibe Coding

#stub

A loosely-scoped term for building software primarily through natural-language directives to a coding agent (e.g., Claude Code), with the human acting as taste-maker and reviewer rather than line-by-line author. Coined in the AI-coding-tools community ~2025.

In the context of this vault, "Vibe Coding infrastructure" refers to the supporting skills, memory systems, and dashboards that make agent-driven development reliable enough to use in anger — not the act of one-off prompting.

## Key Claims

- **Vibe Coding needs infrastructure to scale**, not just a better model. Skills, memory layers, farmers, and dashboards are part of that infra. — [[2026-05-08-ai-hackathon-show-and-tell]]
